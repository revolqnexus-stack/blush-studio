# Blush Fine Makeup Art — Premium React Mockup

Concept redesign for **Blush Fine Makeup Art** (Blush Studio), Jubilee Hills, Hyderabad.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Business config

Edit `src/constants/index.ts` — `SITE_CONFIG`, `TRUST_STATS`, contact numbers, and social links.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
